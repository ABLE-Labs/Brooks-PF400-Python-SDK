# 장비 오류 설명

숫자 코드만 반환돼도 알려진 코드에는 설명과 가능한 확인 사항을 표시합니다.
DeviceError의 code, raw, command는 그대로 보존하며 description과 hint를 추가했습니다.
알 수 없는 코드는 제조사가 보낸 설명을 사용하고, 설명도 없으면 알 수 없는 오류로 표시합니다.
이 목록은 제조사 전체 오류 목록이 아닙니다. 오류 설명을 추가해도 자동 복구나 명령 재전송은 하지 않습니다.

## FreeMode -1009

로봇 제어권이 없는 상태에서 수동 모드를 요청하면 발생합니다. Attach 0은 제어권 해제입니다.
14번 예제는 같은 motion 연결에서 Attach 1을 실행한 뒤 수동 모드를 설정합니다.
오류가 계속되면 전송 결과·제어권 상태와 현재 실행 파일/설치 SDK를 확인해야 합니다.

```text
FreeMode 1: -1009 | No robot attached: 로봇 제어권이 연결되지 않았습니다. | ... attach(1) ...
```
